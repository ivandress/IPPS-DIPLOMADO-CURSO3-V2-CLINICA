# Clínica · API REST

API con Node, Express y MongoDB para médicos y pacientes.

Repositorio: https://github.com/javierfigueroaaaby/IPPS-DIPLOMADO-CURSO3-V2-CLINICA

## Cómo levantarlo

1. Instalar dependencias:

```
yarn install
```

2. Crear el archivo `.env` a partir de `.env.example` y poner tu URL de MongoDB:

```
MONGODB_URI=mongodb+srv://USUARIO:CLAVE@TU-CLUSTER.mongodb.net/clinica
```

3. Levantar el servidor:

```
yarn dev
```

El servidor queda en http://localhost:3001
